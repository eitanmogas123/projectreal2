# חיפוש ספרים

🔗 [לצפייה באתר החי](https://boisterous-dango-81b47e.netlify.app/)       

## תכונות
- חיפוש אוטומטי תוך כדי הקלדה (debounce), בלי צורך בכפתור
- מצב טעינה בזמן שהבקשה בדרך
- טיפול בשגיאות רשת ובמקרה של "אין תוצאות"
- מציג כותרת, סופר ושנת פרסום לכל ספר

## הרצה מקומית
פותחים את index.html בדפדפן. אין צורך בשרת, מפתח API או התקנות.

## מבנה
- index.html — מבנה הדף
- style.css — עיצוב
- app.js — לוגיקה: קריאה ל-API, debounce, טיפול בשגיאות

## מה למדתי בפרויקט הזה
- fetch ו-async/await
- debounce עם setTimeout/clearTimeout
- try/catch לטיפול בשגיאות רשת
